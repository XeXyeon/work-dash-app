## 학습 노트
### 멱등한 API
- 쉽게 말하면: 같은 요청을 여러 번 보내도 결과가 한 번 보낸 것과 같은 API다.
- 정확히는: `PUT`으로 수량을 "5로 설정"하면 멱등이고, `POST`로 "1 더하기"는 멱등이 아니다.
- 왜 여기서 필요했나: 버튼을 빠르게 두 번 누르면 수량이 두 번 올라갔다.
- 우리 코드에서: `CartController.updateQuantity`.
- 스스로 확인할 질문: 삭제 API를 두 번 부르면 두 번째 응답은 무엇이어야 하는가?
