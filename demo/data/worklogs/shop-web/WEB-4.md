# WEB-4 상품 상세 · 장바구니 담기
- 상태: 완료 · {{t:-3h}} · @claude · 시작 {{t:-7h}}

## 계획 (시작할 때 작성)
- 할 일: 상품 상세 화면을 만들고 장바구니 담기 버튼을 API에 연결한다.
- 완료 기준: 상세에서 담으면 장바구니 화면에 그 상품이 보인다

## 무엇을 했나
상품 상세 화면과 담기 버튼을 만들었다. 담은 뒤 장바구니 개수 배지가 바로 바뀐다.

## 검증
- 실행: 화면 테스트 8개 통과, 브라우저에서 담기 → 장바구니 확인.
