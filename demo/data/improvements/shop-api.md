# shop-api 개선 기록

## {{d:-0d}} 동시 주문에서 재고가 음수가 되던 문제
- 종류: 문제 해결
- 관련: ORD-2, ORD-2#1
- 문제: 재고 1개 상품에 주문이 동시에 들어오면 둘 다 성공해 재고가 -1이 됐다
- 원인: 재고 조회와 차감 사이에 락이 없었다
- 해결: 재고 행을 비관적 락으로 잠근 뒤 같은 트랜잭션에서 차감한다
- 전 → 후: 동시 주문 100건에서 초과 판매 7건 → 0건 (측정)
- 재는 방법: 재고 10개 상품에 100건을 동시에 보내는 통합 테스트
- 남은 것: 운영과 같은 격리 수준에서의 대기 시간은 재지 않았다

## {{d:-6d}} 통합 테스트 실행 시간
- 종류: 성능
- 관련: OPS-1
- 문제: 테스트마다 DB 컨테이너를 새로 띄워 전체 실행이 오래 걸렸다
- 해결: 컨테이너 하나를 재사용하고 테스트마다 테이블만 비운다
- 전 → 후: 전체 테스트 4분 10초 → 1분 5초 (측정)
- 재는 방법: 같은 커밋에서 전체 테스트를 3번 돌린 중앙값
